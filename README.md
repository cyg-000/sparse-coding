# Sparse coding and population geometry

Minimal code for *Sparse population codes separate representational geometry from information sharing*.

- `analysis/`: biological analyses, model interventions and statistical audits.
- `figures/`: scripts for the five main figures.

Data: [Steinmetz](https://figshare.com/articles/dataset/steinmetz/9598406), [Stringer](https://figshare.com/articles/dataset/Recordings_of_ten_thousand_neurons_in_visual_cortex_in_response_to_2_800_natural_images/6845348), [IBL](https://www.internationalbrainlab.com/data), [Allen VBN](https://allensdk.readthedocs.io/en/latest/visual_behavior_neuropixels.html), and [TVSD](https://gin.g-node.org/paolo_papale/TVSD).

Install with `pip install -r requirements.txt`. Raw data, caches and trained checkpoints are not included. Set `SPARSE_CODING_ROOT` when the project root is not the current repository.
